                         Gatilhos (`trigger`)
                    

                    

                        Usados em ability-config.yml para definir qual ação do jogador aciona uma habilidade ativável.
                    


                    

                        

                            

                                LEFT_CLICK
                                
Clique esquerdo com a mão (Ataque/Golpe no ar ou objeto).

                            

                            Padrão Enderian
                        


                        

                            

                                RIGHT_CLICK
                                
Clique direito com a mão (Interagir).

                            

                            Comum
                        


                        

                            

                                OFFHAND_SWAP
                                
Troca de item para a mão secundária (Tecla padrão: F).

                            

                            Prático
                        


                        

                            

                                JUMP
                                
Ao dar um pulo (Tecla Espaço).

                            

                            Movimento
                        


                        

                            

                                SNEAK_ON / SNEAK_OFF / SNEAK_TOGGLE
                                
Quando começa a agachar, solta o agachar, ou alterna (Tecla Shift).

                            

                            Padrão Elytrian
                        


                        

                            

                                SPRINT_ON / SPRINT_OFF / SPRINT_TOGGLE
                                
Ao iniciar ou parar de correr.

                            

                            Mobilidade
                        


                        

                            

                                RIGHT_CLICK_CHESTPLATE
                                
Clique direito no slot da peitoral no inventário.

                            

                            Padrão Shulk
                        

                    

                


                
                

                    

                         Condições (`conditions`)
                    

                    

                        Restrições para garantir que o poder só ative sob circunstâncias específicas.
                    


                    

                        

                            EMPTY_HAND
                            
A mão principal do jogador precisa estar sem nenhum item.

                        


                        

                            NO_BLOCK
                            
O clique não pode ter sido feito mirado diretamente num bloco interativo.

                        


                        

                            GLIDING
                            
O jogador precisa estar ativamente voando/planando.

                        


                        

                            CROUCHING
                            
O jogador precisa estar agachado (agachando).

                        


                        

                            HOLDING_SWORD
                            
O jogador precisa estar segurando uma espada.

                        

                    


                    
                    

                        
                        
originmonsters:
  sonic-boom:
    cooldown: 20
    trigger: LEFT_CLICK
    conditions:
      - EMPTY_HAND
      - NO_BLOCK

                         Exemplo de Criação com Skript
                    

                    

                        Ao rodar o Skript no Paper, o Origins-Reborn se registra como addon automaticamente. Você só precisa definir a habilidade no Skript e colocar no JSON da sua Origem!
                    

                    
# 1. Registre o poder no carregamento do Skript:
on load:
    register an ability with key "skript:super_pulo" and title "Super Pulo Celestial" and description "Te lança para o alto ao ativar."

# 2. Escute quando o jogador ativa o poder:
on origins reborn ability trigger:
    if event-string is "super_pulo":
        push player upwards at speed 2.5
        send "&aVocê ativou o Super Pulo!" to player
